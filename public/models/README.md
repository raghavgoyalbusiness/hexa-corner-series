# Production 3D models (PLACEHOLDER)

Drop the Draco-compressed product model here as `hexa-speaker.glb`, then set
`NEXT_PUBLIC_MODEL_SOURCE=glb`. Until then the site renders the procedural model
in `src/components/three/models/`.

Required node names: `Grille`, `Driver`, `Housing`, `MagnetDisc`, `CornerPlate`.
See the project README → "Swapping in real assets".
